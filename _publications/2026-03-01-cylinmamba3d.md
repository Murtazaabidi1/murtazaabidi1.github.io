A cylindrical state-space framework for efficient 3D point-cloud learning with linear-time modeling. The Cylindrical 3D Mamba block integrates a Cylindrical State Space Module (C-SSM) with Local Neighborhood Processing (LNP), combining geometry-aware token ordering with bidirectional state propagation.
